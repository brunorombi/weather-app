# 🌤️ Weather App

A simple and responsive weather application that allows users to search for a city and instantly get current weather information.

## 🚀 Live Demo  
👉 https://brunorombi.github.io/weather-app/

---

## ✨ Features

- 🔍 Search weather by city name  
- 🌡️ Displays current temperature in Celsius  
- 📍 Shows city name and current time  
- 📅 Displays formatted date  
- 🌥️ Dynamic weather icons based on conditions  
- ⚠️ Input validation and error handling  
- ⏳ Loading indicator while fetching data  

---

## 🛠️ Technologies Used

- JavaScript (ES6 Modules)
- HTML5
- CSS3
- Vite
- Visual Crossing Weather API

---

---

## ⚙️ How It Works

1. User enters a city name  
2. The app validates the input  
3. A request is sent to the weather API  
4. Data is processed into a `Weather` class  
5. UI updates dynamically with the results  

---

## ❗ Error Handling

- Empty input  
- Invalid characters (only letters allowed)  
- City not found  
- API request failures
